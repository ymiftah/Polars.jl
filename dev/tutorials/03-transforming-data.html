Transforming Data ​

Selecting and computing columns ​

select keeps only the columns/expressions you list; with_columns keeps all existing columns and adds/overwrites the ones you give it. Both accept any number of Exprs, built from col (reference a column), lit (a literal value that broadcasts), and alias (rename the result):

julia
select(
    orders,
    col("order_id"),
    (col("quantity") * col("unit_price")) |> alias("revenue"),
)

Conditional logic with when/then/otherwise ​

when builds a ternary expression: then where the condition holds, otherwise elsewhere. Use it to bucket orders into "large" vs. "small":

julia
with_columns(
    orders,

)

Handling missing and NaN values ​

fill_null and fill_nan replace missing/NaN values with a fallback expression — useful after a join or a computation that can produce either:

julia
with_missing = DataFrame((; x = [1.0, missing, 3.0]))
select(with_missing, fill_null(col("x"), lit(0.0)) |> alias("x_filled"))
3×1 DataFrame
 x_filled 
 Float64  
──────────
      1.0
      0.0
      3.0

Membership checks ​

is_in tests whether each value appears in a set built from implodeing a list of literals — handy for filtering to a subset of categories:

julia
coffee_only = implode(lit(1)) # product_id 1 = Espresso; implode(lit(1), lit(2)) for more values
filter(orders, is_in(col("product_id"), coffee_only))
